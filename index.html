搜尋邏輯說明

  • 重點指引：每週一 06:33（台北時間）由 Claude 自動搜尋各科近兩週新發布的 guideline、consensus、practice parameter、ACR Appropriateness Criteria、RADS 新版本與 FDA 影像安全通報。每條須在 PubMed 查到文章編號並核對標題，或有 DOI／學會官網，查不到不收。勾選「保留」的項目在更新後仍保留（存在你的瀏覽器）。預設只顯示本週新項目與已保留項目；舊週次的項目不會刪除，可用上方「週次」選單切換查看（保留最近 12 週）。
  • IF：期刊的 Clarivate Journal Impact Factor，優先採用 JCR 2026 年版公布的 2025 IF，數值取自期刊、出版社或學會官網；非 2025 年的數值會在括號註明年份，官網沒寫年份者只列數值。「無 IF」表示期刊未被 JCR 收錄；查不到可靠官方數值者不標示。
  • 最新文章：直接向 PubMed 即時查詢，分四區各取最新 10 篇，依發表日期排序：
    · Consensus / Guideline：科別關鍵字 + 影像關鍵字 + 文獻類型為 guideline／practice guideline／consensus statement，或標題含 consensus、recommendation、appropriateness criteria、reporting and data system、statement；不限期刊。
    · Meta-analysis：科別關鍵字 + 影像關鍵字 + 文獻類型為 meta-analysis 或 systematic review；不限期刊。
    · Review：科別關鍵字 + 指定期刊 + 文獻類型為 review（排除 meta-analysis、systematic review）。
    · Original：科別關鍵字 + 指定期刊，排除 review、meta-analysis、systematic review、guideline、consensus statement、editorial、comment、letter。
    同一篇只歸一區，優先順序 Consensus / Guideline → Meta-analysis → Review → Original。結果在瀏覽器保留 6 小時，可按「重新整理」強制更新。
  • 指定期刊：各科專科期刊，加上 Radiology、AJR、Eur Radiol、RadioGraphics、JACR、Korean J Radiol、Insights Imaging。
  • 期間：7d／30d／90d／365d／all 以 PubMed 收錄日期（Entrez date）篩選，影響「最新文章」與「查詢連結」，不影響「重點指引」。
  • 查詢連結：三個按鈕用相同條件在 PubMed 網站開啟完整結果（最新期刊文章、新指引／共識、最新 review），另有單一期刊最新文章捷徑。
  • 影像關鍵字：imaging、radiolog*、CT、MRI、ultrasound、PET。
  • 科別關鍵字：每個面板有預設關鍵字（例如 Thoracic 為 thoracic、chest、lung、pulmonary、pleura*）；點「查詢連結」裡的按鈕，可在 PubMed 搜尋框看到完整條件。
  • 文章類別標籤：依 PubMed 的 Publication Type 判定，優先順序 Guideline → Consensus → Meta-analysis → Systematic Review → RCT → Clinical Trial → Review → Case Report → Commentary → Original；只標為一般期刊文章、但標題含 consensus、recommendations、practice parameter、position statement 者改標 Consensus。非 PubMed 文章（RADS、學會官網、FDA 通報）由人工判定。
  • 四區分組：Original 區含 Original、RCT、Clinical Trial、Case Report、Commentary、News；Review 區為 Review；Meta-analysis 區含 Meta-analysis、Systematic Review；Consensus / Guideline 區含 Guideline、Consensus、RADS、Statement、FDA 通報。每區先顯示 2 篇與篇數，點擊展開。
